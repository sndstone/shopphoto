# Upstream license sources

These are complete upstream license texts, retrieved 2026-10-15. Model bundles
also carry `NOTICE.txt` with their specific weight source/revision and conversion
disclosures. A code license is not a blanket grant for every training dataset
or pretrained model; the Torchvision notice preserves that distinction.

- `swinir-LICENSE.txt`: https://raw.githubusercontent.com/JingyunLiang/SwinIR/main/LICENSE
