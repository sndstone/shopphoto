ShopPhoto · 0.2.3 · implementation pass 2 Sep 2026

What the editor still needs, and in what order

Phases 0–9 of the build spec are complete and the pipeline is unusually deep for a young editor. The gaps are now in day-to-day editing tools, geometry, the library, and shipping on more than one machine.

Sources: README, BUILD.md, PROGRESS.md, docs/, crate sources Working tree: mixed pre-existing changes preserved; no automatic commit/tag

What exists today

A compressed inventory of what is built and verified, so the plan below is read against the right baseline.

RAW & color

  • 3FR/FFF/DNG and most rawler formats; X2D II 100C active-area fix
  • Full GPU develop pipeline, scene-linear Rec.2020 f16
  • Profiles: embedded matrix, Adobe DCP import, Reference Match fitter
  • Luma-invariant chroma-plane color rendering
  • Fuzzed decoder with a structural pre-flight guard

Tone & detail

  • Exposure, brightness, contrast, H/S/W/B, parametric + RGB point curves
  • 8-band Oklab HSL, three-way grading, monochrome mixer
  • Clarity, texture, dehaze, vignette, masked sharpening, deterministic grain
  • Conservative Auto Balance and 11 built-in presets
  • Hot pixels, pre-demosaic NR, NLM luma + Oklab chroma NR, 1:1 loupe
  • AI RAW denoise

Lens & HDR

  • Per-CFA shading plus radial distortion/lateral-CA coefficients in .splens
  • Two-scale purple/green axial-CA defringe with pickers and Auto
  • macOS EDR display, split before/after, proof spaces
  • PQ export, Ultra HDR JPEG with gain map, hue-preserving shoulder

Export & library

  • JPEG, TIFF 8/16, PNG 8/16, AVIF; sRGB / P3 / Rec.2020 ICC
  • Five sizing modes, output sharpening, border/PNG watermark, non-blocking batch
  • 2×2 exact / 3×3 / 4×4 supersampling
  • SQLite catalog, metadata search/filters, collections, duplicates, XMP
  • 20 GB network cache; .spedit snapshots/history and batch settings sync

App & release

  • Studio Console UI, undo/redo, shortcut sheet, F12 overlay, welcome screen
  • Daily read-only update check
  • Universal macOS DMG, NSIS, AppImage/Flatpak scripts; CI on three OSes
  • 250+ tests, golden renders, perf budgets, criterion benches

The plan

Every item names the evidence it came from. Priority is what it costs the primary user to live without it; effort is a rough S/M/L for one focused person.

Suggested order

Three passes. The first is short and removes risk; the second is the single biggest capability gap; the third rounds out a 1.0.
