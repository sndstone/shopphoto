What is preloaded

The Lens selector includes XCD 20–35E, 21, 25, 25V, 28P, 30, 35–75, 35–100E, 38, 38V, 45, 45 II, 45P, 55, 55V, 65, 75P, 80, 90, 90V, 120 Macro and 135 + 1.7×. These cover current names plus the historical maker-note variants found in the installed resource set and local Hasselblad sample files. A manual choice is stored separately as lens_model_override and participates in matching a genuine ShopPhoto .splens profile if one is installed later.

Result: “Unknown” can be replaced with the correct XCD identity immediately. The correction status beneath the selector remains “no ShopPhoto shading calibration yet” until real grid data is present.

Why the Phocus GMaps are not copied

Hasselblad’s installed Phocus application contains 59 XCD GMap files covering multiple aperture generations and zoom focal positions. Inspection found opaque, high-entropy binary payloads with no public interchange schema or documented API. Renaming or copying those files into ShopPhoto would not make them usable and could falsely imply a correction was applied.

Hasselblad states that Phocus calculates corrections using lens design plus shot distance and aperture. That is more than a display name and more than a single vignette grid. The older Phocus manual likewise describes lens-model-specific chromatic-aberration, distortion and vignetting correction driven by capture metadata.

Boundary: this release preloads the lens catalog, not Hasselblad’s proprietary optical model. The private data remains inside Phocus.
