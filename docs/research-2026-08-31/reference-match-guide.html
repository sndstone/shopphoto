Practical guide

Build a profile from files you own.

Reference Match compares ShopPhoto’s RAW render with neutral 16-bit TIFFs you create in a trusted renderer. Good capture discipline matters more than the number of files.

OverviewPhocus research

1 · Photograph useful variation

  • Use one camera model per profile and a tripod when possible.
  • Include a color target plus real materials: skin, foliage, fabric, painted surfaces, metals, and neutrals.
  • Avoid clipped channels and deep noise-floor samples; bracket if necessary.
  • For multi-illuminant work, measure actual CCT. Useful clean-room targets are 2856 K, about 4000 K, about 5500 K, and 6504 K—not private camera-maker nodes.

2 · Export neutral reference TIFFs

3 · Fit and judge

Select 3–10 RAWs, then the TIFF folder. ShopPhoto samples matched coordinates, withholds validation samples, fits its own matrix/chromaticity/curve/residual stages, and reports holdout ΔE00.

<2

Strong target

Mean holdout ΔE00 below 2 is a useful goal, but inspect the worst patches and real photographs too.

3–10

Varied frames

More near-duplicate frames add less value than a few well-exposed scenes with different materials and light.

Ownership boundary: only fit from reference exports and RAWs you are entitled to use. A fitted profile is user calibration—not Hasselblad factory color, HNCS, or a copied LUT.

4 · Validate before relying on it

  • Keep at least one scene out of the fit and compare it at multiple exposures.
  • Check neutral grays, skin, saturated flowers/signage, and highlight hue stability.
  • Repeat under another illuminant; a single-light fit should not be advertised as universal.
  • Keep the source files and document renderer/version/settings with the profile.
