HDR needs room to glow.

The former curve started squeezing highlights before reference white. The replacement protects normal brightness, then bends specular energy smoothly into the selected display headroom.

OverviewNext: Auto Balance

Input and output are multiples of diffuse/reference white. Move the control to compare display headroom.

New shoulder

knee = mix(1.0, 0.82, rolloff)

y = knee + span × tanh((x-knee)/span)

The ceiling remains fractionally below peak to avoid a hard code-value plateau.

Color stability

The SDR fallback derives one scale factor from Rec.2020 luminance while samples are still in the working space. Applying that same scale to RGB keeps ratios—and therefore hue—far more stable than compressing channels independently.

A concrete 2-stop example

What the standards and platforms imply

SourceUseful principleShopPhoto decision
Apple EDR1.0 is reference white; values above it are highlights; available headroom is dynamic.Keep ordinary whites near 1.0, make peak an explicit display parameter.
Apple adaptive gainDiffuse white is anchored at 203 nits and headroom can be expressed in stops.Expose reference-white nits and headroom separately in the UI.
Android Ultra HDR / ISO 21496-1A base SDR rendition plus logarithmic gain map preserves compatibility.Keep SDR fallback visually sound and Ultra HDR metadata interoperable.
ACES 2Its output tone scale is smooth, monotonic, display-aware, and explicitly non-asymptotic.Borrow smoothness and monotonicity, but document a deliberate difference: ShopPhoto’s user-selected display cap uses a near-ceiling tanh asymptote. Ordinary scene values retain a slope instead of landing on peak-white code values.
Perceptual target: a lamp, reflection, or cloud edge should become noticeably brighter than paper white, while retaining gradation. Peak white is a scarce endpoint, not a default landing zone.
